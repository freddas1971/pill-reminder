# Pill Reminder

A simple Android app that rings at pill time and shows a photo of which pill to take.

- Add each pill with a photo, instructions and the times to take it
- Every day, certain weekdays, or every few days, with optional start/end dates
- Loud alarm-style reminder with the pill photo, also over the lock screen
- "I've taken it" / "Remind me in 10 min" buttons; repeats if not ticked off
- Today screen showing what's taken, due and missed

Every push to `main` builds a new APK automatically. Download it from the **latest** release.
